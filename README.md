# 🍔 Responsive FoodMunch Website

A fully responsive food ordering website built using **HTML5, CSS3, and Bootstrap Grid System**. This project demonstrates modern UI design principles with a mobile-first approach and clean layout structure.

---

## 🌐 Live Demo

https://kolakanisandeepkumar2003.github.io/responsive-foodmunch-website/

---

## 🚀 Features

* 📱 Fully responsive design (mobile, tablet, desktop)
* 🎨 Clean and modern user interface
* 🧭 Navigation bar with smooth scrolling
* 🍕 Food menu sections with attractive layout
* 📞 Contact section and footer
* ⚡ Built using Bootstrap Grid System

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* Bootstrap
